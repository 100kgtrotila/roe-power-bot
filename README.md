# ROE Power Bot

Приватний Telegram-бот на TypeScript для графіків [Рівнеобленерго](https://www.roe.vsei.ua/disconnections).
Працює на Cloudflare Workers: після розгортання комп'ютер власника не потрібен.

**Налаштування й хостинг: [український покроковий гайд](docs/deployment.md).**

## Поведінка

- Вибір підчерги 1.1–6.2 або всіх, окремі налаштування кожного користувача.
- Одна спільна перевірка джерела не частіше ніж раз на 5 хвилин. Ручний перегляд читає кеш.
- Початкове «Очікується» мовчить. Новий або змінений графік надходить після найближчої успішної перевірки; незмінний не повторюється.
- Графік на завтра надходить після публікації. Перехід опублікованих годин до «Очікується» повідомляється один раз як уточнення.
- Нагадування за 15, 30 або 60 хвилин; початково вимкнені. Години — за Києвом.
- Оновлення й нагадування вмикаються незалежно. `/stop` відкриває меню; для зупинки натисніть відповідну кнопку.
- Підписки й підтверджені надсилання зберігаються в D1 між перезапусками.
- Доступ лише у приватних чатах за списком Telegram ID.
- Посилання на джерело надсилаються без карток прев'ю. Завантажувач пише безпечні
  діагностичні події для `wrangler tail`; пояснення полів — у гайді розгортання.

Після `/start` з'являється постійне меню внизу чату: «Мій графік», «Усі черги»,
«Моя підчерга», «Нагадування», «Налаштування», «Стан перевірок». Підчерга та
інтервал обираються кнопками під повідомленням; поточний вибір позначений ✓.
На підекранах є «Головне меню». Якщо клавіатуру приховано, відкрийте її значком
біля поля введення або знову надішліть `/start`.

Графік показує дату словами та групує години під одним заголовком підчерги.
«Стан перевірок» показує збережені часи останньої спроби, успішного розбору
та наступної спроби; відрізняє відсутність даних від помилки чи затримки.
Кнопка не створює додаткового запиту до сайту.

Команди також доступні: `/start`, `/queue`, `/schedule`, `/all`, `/reminders`, `/status`, `/stop`, `/help`.
`/all` показує всю таблицю одноразово без зміни власного вибору. Для постійної
підписки на всі підчерги оберіть «Усі підчерги» у меню вибору.

## Локальний запуск

Потрібні Node.js 22.12+ та pnpm 10.33.0, закріплений у package.json.

```powershell
cd D:\Projects\roe-power-bot
pnpm install --frozen-lockfile
Copy-Item .dev.vars.example .dev.vars
pnpm run db:migrate:local
pnpm dev
```

Заповніть `.dev.vars` за гайдом; не перезаписуйте наявний файл із секретами.
`GET http://localhost:8787/health` перевіряє HTTP-процес, а не токен чи свіжість
даних. Telegram не доставляє webhook на localhost. Автоматичні тести замінюють
зовнішні HTTP-запити та працюють з локальною workerd/D1, без реальних акаунтів.

```powershell
pnpm test
pnpm run typecheck
pnpm run lint
pnpm run build
```

`build` — Wrangler dry-run у `dist/`, без публікації. `deploy` запускається окремо
після налаштування D1. `format` застосовує Biome.

## Структура

| Шлях                                     | Призначення                                   |
| ---------------------------------------- | --------------------------------------------- |
| `src/index.ts`, `src/bot.ts`, `src/bot/` | Webhook, доступ і Telegram-меню               |
| `src/schedule/`                          | Парсинг HTML, завантаження, київський час     |
| `src/db/`, `migrations/`                 | D1, підписки, контроль одночасного виконання  |
| `src/notifications/`, `src/scheduled.ts` | Зміни, нагадування й доставка                 |
| `scripts/telegram-webhook.mjs`           | Налаштування Telegram без токена в аргументах |
| `tests/`                                 | Предметні тести й інтеграція з локальною D1   |

## Обмеження та перевірка

Звичайна затримка виявлення зміни — приблизно 0–5 хвилин плюс доставка; збої
сервісів можуть її збільшити. Доступність джерела не гарантована. Кеш під час
збою зберігається; ручний перегляд та нагадування попереджають про застарілість.
Бот показує опублікований графік, а не фактичний стан електропостачання.

Парсер розпізнає години й «Очікується». Обробка стану «Відключень немає» є в
предметній логіці, але відповідний маркер реального сайту ще не підтверджено,
тому парсер його не вгадує. Невідомий текст або порожня клітинка зберігають
останній коректний графік із попередженням, а не скасовують відключення.

Якщо процес обірветься між прийняттям повідомлення Telegram і записом у D1,
повтор можливий: exactly-once не гарантується.

Cron працює щохвилини для нагадувань; запити до сайту мають окремий інтервал
щонайменше 5 хвилин і backoff після помилок. Розсилки обробляються порціями й
можуть займати кілька циклів. Це бот для малого приватного списку. Достатність
безкоштовного тарифу потрібно перевірити за CPU й D1 на реальному акаунті.

Локальні перевірки не означають, що бот уже захощений: справжні токен, D1,
webhook і доставка перевіряються власником після розгортання за гайдом.
