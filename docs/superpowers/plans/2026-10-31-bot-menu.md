# Bot Menu Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** керування кнопками й компактні графіки замість спілкування командами.
**Architecture:** існуючі durable intents і grammY routing; D1 лише читається для status.
**Tech Stack:** наявні TypeScript, grammY, pnpm, Vitest, Biome.
**Spec:** `../specs/2026-10-31-bot-menu-design.md`, погоджено користувачем.

## Global Constraints

Зберегти бізнес-правила, allowlist, deduplication, ліміти довжини й stale provenance.
Без міграцій, нових залежностей, deploy, зміни токенів або живих повідомлень.

## Review Focus

Reply-кнопки не мають обходити доступ; навігація не змінює підписку; статус не
маскує відсутність/простроченість даних; retry після нового формату не губить
baseline; великі графіки й застарілі дати залишаються повними.
